# 🎮 Godot Object Selection Game

> **Goal:** Build my first fully completed 2D game in Godot while learning engine basics and tracking daily progress.

---

## 📌 Project Overview
In this game, the player controls a character who must interact with a box to select one of three objects based on on-screen prompts:

* 🎯 **Objective:** Select the correct object prompted by the game.
* 💯 **Scoring:** Correct choices increase points; incorrect choices decrease points.
* ⏱️ **Timer:** Each round runs on a **30-second loop**.
